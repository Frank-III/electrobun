## Codebase Patterns
- Use `signal()` accessor syntax for all signal reads in SolidJS
- SolidJS refs are direct values (`let ref: T | undefined`), not objects with `.current`
- Use `<Show when={}>` instead of `{condition && <Component />}`
- Use `<For each={}>` instead of `.map()` in JSX
- Use `onInput` instead of `onChange` for text inputs
- CSS properties in style objects use kebab-case: `"background-color"` not `backgroundColor`
- Replace `React.SVGProps` with `JSX.SvgSVGAttributes`
- Effects don't take dependency arrays - SolidJS auto-tracks
- Replace `React.ReactNode` with `JSX.Element`
- Replace `forwardRef` with props-based ref passing: `ref?: HTMLElement | ((el: HTMLElement) => void)`
- Use `splitProps` for component props destructuring
- Kobalte components (Tooltip, Popover) don't support `asChild` like Radix
- Use `Portal` from solid-js/web, not `createPortal` (and wrap children, not pass to function)
- Use `onCleanup()` in effects instead of returning a cleanup function
- Use `import type { X }` for type-only imports (verbatimModuleSyntax)
- tRPC still uses React Query wrapper - `isLoading` and `data` are not SolidJS signals yet
- useAtomValue returns an accessor: `const value = useAtomValue(atom); value().someProperty` not `value.someProperty`
- Replace React.DragEvent/React.MouseEvent with native DOM types (DragEvent, MouseEvent)
- Delete stale .js files in src/ folders - they may be old transpiled output from before migration
- Replace `React.KeyboardEvent` with native `KeyboardEvent`, `React.CSSProperties` with `JSX.CSSProperties`
- For ref collections, use `Map<string, HTMLElement>` directly, not `createSignal<Map<...>>`
- Replace `memo(forwardRef(...))` with plain function + `props.ref?.(element)` pattern
